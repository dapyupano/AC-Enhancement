Baseline vs Enhanced Automaton

Each engine detects its own set of patterns from the same prescription — the Baseline algorithm matches raw substrings with no boundary or context checking, while the Enhanced algorithm applies boundary checking and context-aware validation before a term counts as a match. This page builds a separate automaton from each engine's own detected patterns (not a shared/merged list), so you can see how that filtering changes the resulting automaton's size and shape.
